# GabGames — Tier List de Engenharia da Computação\n\n**Portfólio:** https://iamdatagabs.github.io/iamdatagabs/portfolio/

Um mini game estático para montar sua tier list das disciplinas de Engenharia da Computação.

## Como jogar

1. Abra o site.
2. Arraste cada disciplina para uma categoria: S, A, B, C, D ou F.
3. Use **Embaralhar disciplinas** para reorganizar as matérias que ainda não classificou.
4. Clique em **Copiar minha tier list** para compartilhar o resultado.

O progresso é salvo automaticamente no armazenamento local do navegador.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- Sem dependências ou etapa de build

## Publicação

O arquivo principal é `index.html`. Para publicar com GitHub Pages, configure **Settings → Pages → Deploy from a branch → main → /(root)**.
